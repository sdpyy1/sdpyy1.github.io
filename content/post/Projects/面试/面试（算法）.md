## 贪心和动态规划的区别？

> 贪心是在当前状态下评估最优解
>
> 动态规划是依靠上一个子问题的解来推算当前问题的解

# 找众数

> 题目出现寻找数目大于一半的数字，就是在找众数

1. 把数组排序，中间的数一定是众数
2. 投票法，假设第一个数是众数，那么如果后续不是他，就-1票，减到0票，换当前数为众数

```c++
int majorityElement(vector<int>& nums) {
    int curNum = nums[0];
    int tick = 0;

    for(int i = 0;i<nums.size();i++){
        if(tick == 0){ // 投票全部抵消时，当前数字作为当前的众数
            curNum = nums[i];
        }
        if(nums[i] == curNum){
            tick++;
        }else{
            tick--;

        }
    }
    return curNum;
}
```

# 买卖股票

> 遍历到某一天的最大利润 = 当天股票价格-最低买入价格 > 上一天的最大利润?当天股票价格-最低买入价格：不更新
>
> 动态规划的一种，每一天的最大利润可由上一天的最大利润和 之前的最低价格来更新

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        // 更新当前状态下的最大利润
        // 记录前边最小损失
        // 下一天如果卖出后利润高于当前记录的最大利润，就更新利润
        int profix = 0;
        int cost = prices[0];
        for(int i = 0;i<prices.size();i++){
            if(prices[i] < cost){
                cost = prices[i];
            }
            if(prices[i] - cost > profix){
                profix = prices[i] - cost;
            }
        }
        return profix;
    }
};
```
